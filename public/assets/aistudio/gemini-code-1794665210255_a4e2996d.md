1. **Slump Cone Test of Fresh Concrete (স্লাম্প টেস্ট — ASTM C143)**:
   - Cone dimensions: Bottom $\varnothing = 200\text{ mm}$ ($8"$), Top $\varnothing = 100\text{ mm}$ ($4"$), Height $H = 300\text{ mm}$ ($12"$); tamping rod $\varnothing 16\text{ mm}$, length $600\text{ mm}$, 3 layers (or 4 layers per PWD), 25 blows per layer.
   - Formula: $$\text{Slump} = H_{\text{cone}} (300\text{ mm}) - H_{\text{subsided}}\ (\text{mm or inches})$$
   - Slump Type Visual & Numerical Chart: True Slump, Zero Slump, Shear Slump (lack of cohesion — remix/retest), Collapse Slump (excess water/segregation — reject batch).
   - Standard Slump Table by Element: Road Pavement ($25 - 50\text{ mm}$), Mass Footing ($50 - 75\text{ mm}$), Normal Beam/Slab/Column ($75 - 125\text{ mm}$), Pumped Concrete ($100 - 150\text{ mm}$), Cast-in-Situ Bored Pile Tremie Concrete ($150 - 200\text{ mm}$).
2. **Concrete Cylinder ($100\times 200\text{ mm}$ / $150\times 300\text{ mm}$) & Cube ($150\times 150\text{ mm}$) Compressive Strength Test (ASTM C39 / BS EN 12390 / BNBC-2020)**:
   - Formulas:
     $$A_{\text{cyl}} = \frac{\pi d^2}{4}, \quad A_{\text{cube}} = b^2, \quad f_c = \frac{P_{\max}}{A}\ (\text{MPa and psi})$$
     $$f'_{\text{cyl}} \approx 0.80 \times f_{\text{cube}}$$
   - Age-Strength Maturity Expectations: 7-day $\approx 65\% - 70\%$ of $f'_c$; 14-day $\approx 85\% - 90\%$ of $f'_c$; 28-day $\ge 100\%$ of $f'_c$.
   - **BNBC-2020 / ACI 318-19 Strict Acceptance Criteria Calculator**:
     1. Average of any 3 consecutive strength tests $\ge f'_c$.
     2. No individual strength test (average of 2 cylinders) falls below $f'_c - 3.5\text{ MPa}$ ($500\text{ psi}$) when $f'_c \le 35\text{ MPa}$, or below $0.90 f'_c$ when $f'_c > 35\text{ MPa}$.

3. **Drilled Concrete Core Test (কোর কাটিং টেস্ট — ASTM C42 / ACI 318)**:
   - Length-to-Diameter ($L/D$) correction factor ($k_{ld}$): $L/D = 2.0 \Rightarrow 1.00$; $1.75 \Rightarrow 0.98$; $1.50 \Rightarrow 0.96$; $1.25 \Rightarrow 0.93$; $1.00 \Rightarrow 0.87$.
   - Formula: $$f_{\text{core,corrected}} = k_{ld} \times \frac{P_{\max}}{\pi D^2 / 4}$$
   - ACI 318 / BNBC Acceptance Rule: Structural adequacy is satisfied if average of 3 cores $\ge 0.85 f'_c$ AND no single core is $< 0.75 f'_c$.
4. **Rebound (Schmidt) Hammer NDT Test (স্মিড হ্যামার টেস্ট — ASTM C805)**:

5. **Ultrasonic Pulse Velocity (UPV) NDT Test (আল্ট্রাসনিক পালস ভেলোসিটি — ASTM C597)**:
   - Direct, Semi-Direct, and Indirect transmission modes.
   - Formula: $$V = \frac{L}{T}\ (\text{km/s or m/s})$$ where $L$ = path length, $T$ = transit time in $\mu\text{s}$.

### Category 5: Reinforcing Steel Bar (Rebar) Tests (রড বা স্টিল পরীক্ষা — BDS ISO 6935-2 / ASTM A615 / A706)

1. **Field Unit Weight per Meter & Rolling Margin Tolerance Check (সাইটে রডের ওজন ও টলারেন্স পরীক্ষা)**:
   - Theoretical Unit Weight Formula:
     $$w_{\text{std}} = \frac{d^2}{162.2}\ (\text{kg/m}) \quad \text{or} \quad w_{\text{ft}} = \frac{d^2}{532.15}\ (\text{kg/ft})$$
   - Actual Measured Weight & Rolling Margin Formula:
     $$w_{\text{actual}} = \frac{W_{\text{sample}}}{L_{\text{sample}}}, \quad \text{Rolling Margin (\%)} = \frac{w_{\text{actual}} - w_{\text{std}}}{w_{\text{std}}} \times 100$$
   - Standard Tolerance Chart per BDS ISO 6935-2 / BS 4449:
     - $d = 8\text{ mm}$ to $12\text{ mm}$: Permissible deviation $\pm 6.0\%$.
     - $d = 16\text{ mm}$ to $50\text{ mm}$: Permissible deviation $\pm 4.5\%$.
     - Explain how under-weight bars reduce effective cross-sectional steel area $A_{s,\text{eff}} = A_{s,\text{nom}} \times (w_{\text{actual}} / w_{\text{std}})$ and when to reject a lot or adjust bar spacing.
2. **UTM Tensile, Yield Strength ($f_y$), Ultimate Strength ($f_u$) & Seismic Ductility Ratio ($f_u / f_y$) Test (ASTM A370 / BNBC-2020)**:
   - Formulas:
     $$A_0 = \frac{\pi d_{\text{eff}}^2}{4}, \quad f_y = \frac{P_{\text{yield}}}{A_0}, \quad f_u = \frac{P_{\text{ult}}}{A_0}, \quad \text{Ductility Ratio} = \frac{f_u}{f_y}$$
   - **BNBC-2020 Seismic Ductility (Class D / B500DWR / ASTM A706) Strict Checks**:
     1. $f_{y,\text{actual}} \ge f_{y,\text{specified}}$ (e.g., $\ge 500\text{ MPa}$ for 500W, $\ge 420\text{ MPa}$ for Grade 60).
     2. Over-strength upper cap: $f_{y,\text{actual}} \le f_{y,\text{specified}} + 125\text{ MPa}$ (i.e., $\le 625\text{ MPa}$ for 500W so plastic hinges form as designed without brittle shear failure).
     3. Strain-hardening ratio: $\frac{f_{u,\text{actual}}}{f_{y,\text{actual}}} \ge 1.25$ (BNBC-2020 / ACI 318 seismic requirement) or $\ge 1.15$ (ISO B500C).
3. **Percentage Elongation Test (রডের প্রসারণশীলতা পরীক্ষা)**:
   - Gauge length $L_0 = 5 d$ (ISO) or $200\text{ mm}$ ($8"$ ASTM).
   - Formula: $$\text{Elongation (\%)} = \frac{L_f - L_0}{L_0} \times 100$$
   - Standard Chart: $\ge 14\% - 16\%$ for ductile seismic Grade 500W / 400W; $< 12\%$ indicates brittle re-rolled/induction-furnace scrap steel (Reject).
4. **180° Bend & Rebend Test (রডের বেন্ড ও রিবেন্ড পরীক্ষা)**:
   - Mandrel diameter table ($3d$ to $7d$ based on bar diameter and grade) and visual inspection criteria (zero transverse cracks on outer convex surface).
