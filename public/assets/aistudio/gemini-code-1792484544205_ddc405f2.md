Design and implement a world-class, responsive, multi-platform Material You (Material Design 3) Dashboard for PB CivilLab that works seamlessly across Mobile (iOS/Android), Tablets, and Desktop Web.

Key Dashboard UI/UX Requirements:
1. **Dynamic Material You Layout & Theming**: Use M3 surface containers, tonal elevations, rounded cards (`rounded-3xl` / `rounded-2xl`), and dynamic container coloring based on active project status.
2. **Project Summary & KPI Command Cards**: A top hero grid featuring active project metrics (Grand Total BOQ, DCR Compliance status, Total Steel Weight in Tonnes, and Active Engineer of Record credentials) with gorgeous Framer Motion entrance animations.
3. **Quick Launcher Grid for 11+ Engineering Modules**: An organized, filterable grid of cards with Lucide icons, short code standards badges (BNBC-2020, ACI-318, AISC), and live utilization status indicators.
4. **Recent Calculations & Activity Stream**: A sleek ledger showing recent calculation snapshots, timestamp badges, and instant 1-click restore into active workspaces.
5. **Adaptive Navigation & Touch Targets**: Fully optimized 48px touch targets for jobsite glove/tablet use, bottom navigation bar on mobile viewports, and a collapsable split rail on desktop.
6. **Flawless Organization & Search**: Integrated instant search bar filtering modules, formulas, and recent project files with zero latency.

Ensure clean modular React components, high-performance CSS rendering, and strict adherence to the existing Tailwind CSS and Material 3 design tokens.
