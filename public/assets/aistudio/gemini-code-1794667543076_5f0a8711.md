   - Split-spoon sampler ($\text{OD } 50.8\text{ mm}$, $\text{ID } 35\text{ mm}$), $63.5\text{ kg}$ ($140\text{ lb}$) Donut/Safety hammer dropping $760\text{ mm}$ ($30"$). Record blows for three $150\text{ mm}$ ($6"$) increments ($N_1, N_2, N_3$); discard seating drive $N_1$; Field $N = N_2 + N_3$.

     $$N_{60} = N_{\text{field}} \times \frac{E_m}{60} \times C_B \times C_S \times C_R, \quad C_N = \min\left(\sqrt{\frac{100}{\sigma'_v}},\, 2.0\right), \quad (N_1)_{60} = C_N \times N_{60}$$

### Category 7: Highway, Pavement & Bitumen Tests (রাস্তা, পেভমেন্ট ও বিটুমিন পরীক্ষা — RHD / LGED)

1. **California Bearing Ratio (CBR) Test — 4-Day Soaked (ASTM D1883 / LGED / RHD)**:
   - Standard piston area $1935\text{ mm}^2$ ($3\text{ in}^2$); Standard load at $2.5\text{ mm}$ penetration = $1370\text{ kgf}$ ($13.44\text{ kN}$); Standard load at $5.0\text{ mm}$ penetration = $2055\text{ kgf}$ ($20.15\text{ kN}$).

4. **Marshall Stability, Flow & Bitumen Extraction Test (ASTM D6927 / D2172)**:
